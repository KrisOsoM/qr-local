# Privacy Policy — QR Local

_Last updated: 2026-09-21_

QR Local is designed as a local-first, offline-capable application.

## Data processing

QR payloads (URLs, text, Wi-Fi credentials, phone numbers, email content, vCard data and similar inputs) are processed in the user's browser in order to generate static QR codes.

Imported CSV and XLSX files are processed locally in the browser for batch generation.

QR Local does not intentionally transmit this content to the author or to a remote service.

## Telemetry

QR Local does not include remote analytics or telemetry.

## Local statistics

QR Local can store local usage statistics in the browser's local storage. These statistics can include:

- number of openings;
- number of QR codes generated;
- number of PNG/SVG exports;
- number of generated batches;
- number of QR codes generated in batches;
- QR type counters;
- aggregated daily activity dates and counters.

The local statistics do **not** store QR payloads, URLs, text, contact data, Wi-Fi credentials or imported spreadsheet content.

Local statistics stay in the browser/profile where the application is used. They may be deleted by clearing browser storage or by using QR Local's reset option.

## Network access

The distributed single-file version is intended to operate without network access and contains its required runtime libraries inline. It does not intentionally make outbound network requests.

## Exported files

Generated PNG, SVG, ZIP, manifest and statistics CSV files are saved only when the user explicitly downloads them through the browser.

## Questions

Privacy questions and issues should be filed in the project's public repository once published.
