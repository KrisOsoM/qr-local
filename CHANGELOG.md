# Changelog

## v2.6.1 — 2026-09-14

- Fixed statistics chart layout overflow.
- Improved responsive behavior for narrower screens.
- Kept all v2.6 functionality unchanged.

- Added daily QR-generation history.
- Added local activity charts over time.
- Added statistics period filters.
- Added local statistics CSV export.
- Added migration behavior for earlier unclassified counters.

- Added local-only usage counters.
- Added openings, individual QR generation, PNG/SVG export and batch counters.
- Added first-use and last-use dates.
- Added local statistics reset.

## v2.4 — 2026-09-14

## v2.3 — 2026-09-14

- Converted QR Local to a completely autonomous single-file HTML application.
- Removed Python, installer and native application dependencies.
- Preserved offline QR generation, batch processing and exports.
