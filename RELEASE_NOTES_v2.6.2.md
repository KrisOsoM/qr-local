# QR Local v2.6.2

Released: 2026-10-19

## What changed

- Added a visible **Download QR Local (.html)** button to the hosted application.
- The button saves a self-contained HTML copy that can be opened locally and used without Internet access.
- Added a direct link to the public source repository next to the download control.
- Updated English and Spanish documentation.
- Removed a duplicated local-mode console message.

## Privacy and offline behavior

The download is generated locally in the browser from the self-contained application source. QR content, imported files, and local statistics are not included in the downloaded application file and are not sent to the author.

## Compatibility

The downloaded HTML remains the same local-first distribution model as previous v2.6.x releases: no account, no installation, and no server dependency for QR generation.
